# 스파이더 솔리테어 - 게임 스펙 v0.1

기존 kirbyna/agent 저장소와는 무관한 독립 프로젝트. `spider-solitaire/` 하위에서 개발.

## 1. 난이도 (핵심 요구사항)

표준 스파이더 솔리테어와 동일하게 "사용하는 무늬 수"로 난이도를 구분한다.
무늬가 적을수록 카드를 옮길 때 무늬가 맞을 확률이 높아 쉬워지므로, 체감 난이도와 정확히 일치한다.

| 난이도 | 수트 수 | 구성 |
|---|---|---|
| 쉬움 (Easy) | 1 | ♠ 스페이드만 8벌 (104장 전부 스페이드) |
| 보통 (Medium) | 2 | ♠ 스페이드 + ♥ 하트 각 4벌 |
| 어려움 (Hard) | 4 | ♠♥♦♣ 각 2벌 |

시작 화면에서 난이도 선택 → 새 게임 시작. 게임 중 난이도 변경 불가(새 게임으로만 변경).

## 2. 카드 구성 및 초기 배치

- 총 104장 (표준 카드 2벌, 조커 없음), 난이도에 따라 무늬만 다르게 매핑
- 태블로(tableau) 10개 컬럼
  - 1~4번 컬럼: 6장씩, 맨 위 1장만 open
  - 5~10번 컬럼: 5장씩, 맨 위 1장만 open
  - 합계 54장 배치, 나머지 50장은 스톡(stock)에 대기 (딜 1회당 10개 컬럼에 1장씩 = 총 5회 딜)

## 3. 이동 규칙

- 태블로에서 옮길 수 있는 카드는 컬럼의 open된 카드들 중 위에서부터 랭크가 1씩 연속으로 감소하는 카드(들)
- 여러 장을 한 번에 옮기려면 그 카드들이 **같은 무늬로 연속된 시퀀스**여야 함 (무늬가 섞인 연속 랭크는 맨 위 카드 1장만 이동 가능)
- 이동 대상 컬럼의 맨 위 카드는 옮기는 카드보다 랭크가 정확히 1 높아야 함 (무늬 무관)
- 빈 컬럼에는 랭크/무늬 상관없이 아무 카드(뭉치)나 이동 가능
- 컬럼 맨 위 카드를 옮겨서 그 아래 카드가 드러나면 자동으로 open

## 4. 완성 및 승리 조건

- 같은 무늬로 K→Q→J→...→A 13장이 한 컬럼에 순서대로 모이면 자동으로 해당 시퀀스를 제거(수거 애니메이션)
- 8묶음(무늬별 풀 시퀀스) 전부 제거하면 승리
- 더 이상 유효한 이동이 없고 스톡도 없으면 패배 처리 화면 표시 (재도전/새 게임 유도)

## 5. 스톡 딜

- 스톡에 카드가 남아있으면(10장 단위) 클릭 시 10개 컬럼에 각 1장씩 추가로 open (50장 → 총 5회 딜)
- **하우스 룰**: 빈 컬럼이 있어도 딜 가능 — 빈 컬럼에도 카드가 1장 채워짐 (표준 스파이더 솔리테어는 원래 "빈 컬럼을 먼저 채워야 딜 가능"이 정식 규칙이지만, 캐주얼한 플레이를 위해 이 프로젝트는 완화된 규칙을 채택함)

## 6. 부가 기능 (기본값으로 확정, 이견 있으면 조정)

- **Undo**: 무제한 허용 (초심자 친화적, 표준 캐주얼 스파이더 앱들의 기본값)
- **Hint**: 가능한 유효 이동 1개를 하이라이트
- **점수**: 마이크로소프트 스파이더 방식 채택
  - 이동마다 -1점, 시퀀스 완성마다 +100점, 시작 점수 500점
- **타이머 / 이동 횟수**: 상단 바에 표시
- **자동완성 제안**: 스톡이 비고 더 이상 숨겨진 카드가 없을 때 "자동 정리" 버튼 노출 (선택적, 후순위)
- **저장/이어하기**: 로컬 저장(localStorage → 나중에 iOS는 UserDefaults/파일)으로 앱을 껐다 켜도 진행 중이던 게임 복원
- **사운드/애니메이션**: 최소한의 카드 이동/딜 애니메이션만 우선 구현, 사운드는 후순위(껐다 켤 수 있는 설정으로)

## 7. 화면 구성 (초안)

- **시작 화면**: 난이도 선택(쉬움/보통/어려움) 카드형 버튼 + "이어하기"(저장된 게임 있을 때만 노출)
- **게임 화면**: 상단 바(메뉴, 이동수, 시간, 점수, Undo, Hint) + 10개 태블로 컬럼(가로 스크롤 없이 화면에 맞춤) + 스톡 더미(우측 하단)
- **승리/패배 화면**: 결과(시간, 이동수, 점수, 난이도) + 다시하기/난이도 변경 버튼
- **설정(후순위)**: 사운드 on/off, 애니메이션 속도

## 8. 데이터 모델 개요 (2단계 로직 구현 시 사용)

```
Card { id, rank(1-13), suit, faceUp: bool }
Column { cards: Card[] }  // 마지막 요소가 맨 위
GameState {
  difficulty: 'easy' | 'medium' | 'hard'
  tableau: Column[10]
  stock: Card[][]          // 5장씩 묶음 배열
  foundations: Suit[]      // 완성되어 제거된 시퀀스 기록 (0~8)
  score: number
  moves: number
  elapsedSeconds: number
  history: GameState[]     // undo용 스냅샷 또는 역연산 스택
}
```
